# tests/switch-ratchet.d

Per-ticket floor drops for `tests/switch-ratchet.bh-2320-test.sh` (BH-2407, BH-2426). A ticket that converts bare `[ -f flags/<x>-off ]` reads to `lane_switch` adds ONE file of its own, `<KEY>.drop` (for example `bh-2427.drop`), holding the number of bare reads it removed, and never edits `FLOOR`. The ratchet sums every `*.drop` (only `*.drop`, so this README is ignored) and subtracts it from `FLOOR`. A drop holds one non-negative integer, with `#` comment lines and blank lines allowed and nothing else; a file that does not parse fails the suite with an R0 line naming itself. The reason is parallel builds: when every conversion lowered the same `FLOOR=` line, N sibling builds meant N guaranteed conflicts on a hunk no ticket was about (the fleet rule: never hand-append to a shared index). A `.drop` file is never edited after it merges; a correction is another ticket's file. This README also keeps the directory in git while it holds no `.drop` files.
