# Getting help

- **How do I…?** Start with the guide at [cromford.dev](https://cromford.dev), then ask in [Discussions](https://github.com/cromford-ai/cromford/discussions).
- **Found a bug?** Open an [issue](https://github.com/cromford-ai/cromford/issues/new/choose) with steps to reproduce.
- **Security problem?** See [SECURITY.md](SECURITY.md). Please don't post it publicly.
