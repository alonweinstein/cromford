# Fly idle machine alert (BH-4020)

**What it is:** `bin/fly-idle-check.sh`, a hub lane at `37 6 * * *`. It lists
every app in `FLY_ORG` (`GET /v1/apps?org_slug=`) and each app's machines
(`GET /v1/apps/<app>/machines`), and flags a machine that is `started`, has been
up more than `FLY_IDLE_HOURS` (default 2) since its newest start event, and is
held by nothing the harness knows of: no `state/fly-pool/<p>/<mid>.json`, no
`state/fly/<p>.json` naming it with `<p>-active.json` beside it, no claimed
harness-jobs queue row carrying it. Flagged machines are ONE `logs/ALERTS.log`
line per UTC day:

```
[fly-idle] 2 started machines idle >2h, $0.90/h total: pool-a/<mid> (performance-8/16384MB, up 3h, $0.45/h); ...
```

At most 20 are listed, then `... and K more`. Unknown size reads
`burn unpriced` and adds `(N unpriced)` to the header.

**Why it exists:** the 2026-10-03 cost report counted 42 machines in the org,
25 running, and idle time was only visible after it was billed (#3989).

**How to drive it:**

| what | how |
|---|---|
| the suite (stub `curl` serving the Machines API, mutation runs M1/M2) | `HARNESS_TEST_SANDBOX=1 bash tests/fly-idle-check.bh-4020-test.sh` |
| on the hub, once | `/root/harness/bin/fly-idle-check.sh; tail -1 /root/harness/logs/fly-idle-check.log` |
| usage | `bin/fly-idle-check.sh --help` |

The log line reads `apps= ignored= started= active= idle= age-unknown= partial= queue=`
then `none idle`, `alerted` or `already alerted`.

**Knobs:** on the `fly-idle-check` lane: `FLY_IDLE_HOURS` (2),
`FLY_IDLE_IGNORE_APPS` (comma list), `FLY_IDLE_MAX_APPS` (60),
`FLY_IDLE_HTTP_TIMEOUT` (25), `FLY_PRICES` and `FLY_IDLE_NOW` (env only). Off:
`flags/lane-off-fly-idle-check` or `bin/harness-ctl.sh off fly-idle-check`.

**What must never regress:**

- **GET only.** It never stops, destroys or POSTs to a machine; the suite fails
  on any non-GET request or a stop/destroy URL.
- **A failed read is never "0 idle".** Apps non-2xx or unparseable, or no
  `fly-machines` endpoint: one ALERTS line naming why, rc 1, no marker.
- **No token: `not configured`**, rc 0, no alert. The token never reaches a log.
- **Once per UTC day.** Marker `state/fly-idle-check/<YYYYMMDD>`, written before
  the alert; a failed marker write means no alert.
- **Partial is said.** Apps past the cap or with a failed machines read are
  `partial: K apps not checked`, even when nothing idle was found in the rest.
