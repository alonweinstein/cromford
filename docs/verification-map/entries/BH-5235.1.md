Add `prompts/archie-soul.d/NN-<slug>.md`: a two-digit prefix no other section uses, a lowercase slug (`^[0-9][0-9]-[a-z0-9-]+\.md$`), and a final `\n`. Glob order is prompt order. Pinned by `tests/prompt-sections.bh-5235-test.sh` (P2 name rule and section count, P3 final newline). Live probe on the hub after `bin/harness-sync.sh`: `ls /root/harness/prompts/archie-soul.d/*.md \| wc -l` prints the section count |
