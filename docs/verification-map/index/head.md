# Verification map — cromford

cromford has no user-facing app. Its "features" are cron lanes and shell
libraries on the hub and the fleet boxes, so an entry here answers the operator's
version of the same two questions the template asks: **how do you reach it** (the
cron line and the script), and **how do you drive it** (the fixture suite that
runs the real code, and the files on a live box that show it working).

`TEMPLATE.md` is the shape shipped to target repos and is not an entry.
