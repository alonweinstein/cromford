# Lane runs on Fly: the lease heartbeat and the death count (BH-6125)

**What it is:** a machine that runs a lane-run row keeps its lease alive with a
heartbeat. If another machine took the row, the heartbeat answers 409 `lost`,
and the machine kills its run and sends no report. A row whose lease runs out
at `lane_run.max_attempts` claims becomes `died`, rc 137, and is never claimed
again. Details: [the note](../notes/2026-10-12-BH-6125-lane-run-lease.md).

- Route (harness-jobs, `worker/jobs/src/routes/lane-runs-lease.js`):
  `POST /api/lane-runs/<id>/heartbeat {machine}`. 200 for the claimer of a
  `claimed` row. 409 `{error:"lost", reason}` with reason `no_row`,
  `not_claimed` or `not_claimer`. 400 without a valid machine.
- Death count: `sweepDead` (same file), called by the claim route before each
  claim.
- Loop: `bin/lib/lane-run-heartbeat.sh` (`lrh_start <run_id> <pgid>`,
  `lrh_stop`, `lrh_lost`), called by `bin/lane-run-worker.sh` around each run.
- Rows `lane_run.heartbeat_s` (30, 1..300) and `lane_run.max_attempts`
  (3, 1..20).

**How to drive it:**

| what | how |
|---|---|
| the route and the sweep | `cd worker/jobs && node --test test/lane-run-lease.bh-6125.test.js` |
| the loop, the kill and the take-over, over the real worker | `HARNESS_TEST_SANDBOX=1 bash tests/lane-run-lease.bh-6125-test.sh` |
| died rows on a live worker | `curl -sS -H "authorization: Bearer $HARNESS_SECRET" "$JOBS_URL/api/lane-runs/stats"` (field `died`) |
| on a live box | `grep -E 'lease lost|heartbeat failed|not killed' logs/lane-run-worker.log` |

**What must never regress:**

- A machine that is not the claimer never extends a lease (W3).
- A transport failure or a 5xx never kills a run (H3).
- A bad pgid (`""`, `0`, `1`, negative, the worker's own) is never signalled (H4).
- A lost run is never reported (F3b).
- A `died` row is never claimed again (W4, W4s).
