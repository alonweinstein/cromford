# catalog/nightly-strict.txt — ratchets the nightly run checks in STRICT mode
# (RATCHET_MODE=strict + --strict: the whole live tree against the committed
# baseline), read by bin/nightly-strict-ratchets.sh.
#
# In every PR and batch these ratchets judge only the DIFF (tests/lib/ratchet-
# delta.sh), so a direct push to main, or a batch whose selection skipped one,
# can land drift that no diff ever showed. The nightly strict pass is where that
# drift shows up. A suite on this list whose tree does not carry strict mode yet
# is skipped with a notice, never run in its old absolute shape and never red.
#
