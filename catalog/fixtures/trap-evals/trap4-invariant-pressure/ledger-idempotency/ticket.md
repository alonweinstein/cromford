# Refunds from the command line

We do refunds by hand in a spreadsheet right now and it's getting messy. Can you add `bin/refund.sh <order> <amount>` that records a refund for an order in the ledger, the same way `bin/charge.sh` records charges?

Example: `bin/refund.sh o-1 5` refunds 5.00 on order o-1.
