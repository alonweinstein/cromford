Parallel turns (BH-5336). Each message gets its own turn, and other turns can
run at the same time as yours.
- Edit only this turn's copies of STATE.md and facts.md. The briefing names
  their paths. When the turn ends, they are merged back into the live files
  section by section. An edit to the live files directly can collide with
  another turn.
- Read the OTHER TURNS IN FLIGHT section when your briefing has one. Do not
  start work that another turn already does. If another turn already handles
  this message, say "turn N is already handling this" and stop.
